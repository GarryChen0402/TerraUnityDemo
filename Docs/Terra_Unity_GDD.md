## 1. 游戏概述

### 1.1 游戏名称
**Terra Unity**（工作名）

### 1.2 一句话描述
> 一款 2D 横向沙盒冒险游戏，玩家在程序生成的世界中挖掘、建造、战斗，逐步探索更深的层级并挑战强大的 Boss。

### 1.3 参考作品
| 作品 | 借鉴点 |
|------|--------|
| Terraria | 整体玩法框架、Tile 破坏、合成系统、Boss 进程 |
| Starbound | 生物群系多样性、故事叙事方式 |
| Spelunky | 关卡随机生成思路 |
| Stardew Valley | NPC 互动模式 |

### 1.4 目标受众
- Unity 学习者（首要：作者本人）
- 喜欢沙盒探索类游戏的玩家
- 独立游戏爱好者

### 1.5 游戏规模（学习版）
- 单人游戏
- 世界尺寸：约 4200 × 1200 Tile（中等规模）
- 主线流程：15-25 小时

## 2. 核心玩法循环

```
采集资源 → 合成工具/装备 → 探索更深区域 → 获得更强材料 → 挑战 Boss → 解锁新阶段
    ↑_______________________________________________|
```

### 2.1 基础循环（每局游戏开始）
1. 玩家出生在地表，周围是树木、石块、土方
2. 用手挖掘获得木材，合成基础工具（木镐、木剑）
3. 建造临时庇护所（防止夜晚怪物）
4. 深入地下寻找铜、铁等矿石
5. 合成更好的装备，进入更深层

### 2.2 中期循环
1. 积累足够装备，召唤/遭遇第一个 Boss
2. 击败 Boss 后获得稀有材料，解锁"硬模式"
3. 硬模式开启新的矿石层、新生物群系、更强敌人
4. 继续资源积累 → 挑战更强 Boss

### 2.3 后期循环
1. 最终 Boss 战，需要顶级装备和技巧
2. 通关后开启 NG+ 或挑战模式（可选扩展）

## 3. 世界生成系统

### 3.1 世界结构分层

| 层级 | Y 范围 | 内容 |
|------|--------|------|
| 天空层 | y < 0 | 云朵、飞行岛屿（可选）|
| 地表层 | y 0~150 | 生物群系、树木、建筑遗迹 |
| 地下浅层 | y 150~400 | 普通洞穴、铜铁矿脉 |
| 地下深层 | y 400~900 | 黄金/白金矿脉、地下丛林、神庙 |
| 岩浆地狱 | y 900~1200 | 岩浆、最强敌人、Boss 入口 |

### 3.2 地表生物群系（横向分布）

| 生物群系 | 特征 Tile | 特有怪物 | 特有掉落 |
|----------|-----------|----------|----------|
| 森林 | 草地、橡树 | 史莱姆、飞眼 | 木材、种子 |
| 沙漠 | 沙土、仙人掌 | 沙虫、骷髅 | 沙土、古代卷轴 |
| 雪地 | 雪地、冰砖 | 雪人、冰精灵 | 冰晶、皮毛 |
| 蘑菇丛林 | 蓝色草地、孢子 | 孢子怪 | 发光蘑菇 |
| 腐化之地 | 紫色腐草 | 腐化怪物 | 腐化矿石 |

### 3.3 程序生成技术方案

```
世界生成步骤：
1. 使用 Perlin Noise 生成地形高度曲线（地表起伏）
2. 用多层 Noise 叠加生成洞穴（Cellular Automata 优化）
3. 随机放置矿脉团簇（Flood Fill 算法）
4. 横向分配生物群系（随机宽度段）
5. 放置地标（遗迹、地下神庙、宝箱）
6. 生成出生点（平坦地表附近）
```

#### Unity 实现方案
- **Tile 系统**: 使用 `Unity Tilemap` + `RuleTile` 自动匹配相邻 Tile 贴图
- **Chunk 加载**: 将世界分为 16×16 的 Chunk，仅加载玩家周围的 Chunk（节约性能）
- **数据存储**: 每个 Tile 用 `short` 类型存储 TileID，节约内存

### 3.4 Tile 类型表（部分）

| TileID | 名称 | 硬度 | 掉落物 |
|--------|------|------|--------|
| 1 | 泥土 | 1 | 泥土 ×1 |
| 2 | 石块 | 3 | 石块 ×1 |
| 3 | 木材 | 2 | 木材 ×1 |
| 10 | 铜矿石 | 5 | 铜矿 ×1~3 |
| 11 | 铁矿石 | 7 | 铁矿 ×1~3 |
| 12 | 金矿石 | 10 | 金矿 ×1~2 |
| 20 | 岩浆石 | 15 | — |
| 50 | 宝箱 | — | 随机物品 |

## 4. 玩家系统

### 4.1 角色属性

| 属性 | 初始值 | 最大值 | 说明 |
|------|--------|--------|------|
| 生命值 (HP) | 100 | 400 | 消灭怪物/使用物品可增加上限 |
| 魔法值 (MP) | 20 | 200 | 用于法术类武器 |
| 防御力 | 0 | — | 由装备提供 |
| 移动速度 | 5 | — | 基础值，装备可加成 |
| 跳跃高度 | 5 Tile | — | 鞋类装备可提升 |

### 4.2 移动系统

```
基础移动:
- 左右移动（Rigidbody2D + Input System）
- 单段跳跃（空格键）
- 下坠加速（coyote time 容错）
- 土台穿越（按 S + 跳跃可穿过单向平台）

进阶移动（解锁后）:
- 双段跳（云朵靴）
- 钩爪飞行（蘑菇丝线）
- 飞行（翅膀装备，限时）
```

#### Coyote Time 实现说明
> 玩家走出悬崖后 0.1~0.15 秒内仍可跳跃，避免"卡在边缘"的不良手感。

### 4.3 挖掘系统

- 玩家手持工具，对准 Tile 点击/长按即可挖掘
- 挖掘有**进度条**（基于工具力量和 Tile 硬度计算）
- 挖掘范围：以玩家为中心，鼠标指向的 3×3 范围内最近的 Tile
- 挖掘后 Tile 变为掉落物，玩家靠近自动拾取

```csharp
// 伪代码：挖掘计算
float mineTime = tile.hardness / tool.miningPower;
// 工具力量不足时无法挖掘（e.g. 铜镐挖不动金矿层）
if (tool.miningLevel < tile.requiredLevel) return false;
```

### 4.4 装备槽位

```
头盔     ← 防御 + 特殊属性
胸甲     ← 防御 + 套装效果
护腿     ← 防御 + 移动加成
鞋子     ← 移动 / 飞行能力
副手     ← 盾牌 / 法器
饰品1    ← 特殊加成
饰品2    ← 特殊加成
武器槽   ← 当前手持武器（快捷栏选择）
```

## 5. 战斗系统

### 5.1 武器分类

| 类型 | 代表武器 | 攻击方式 | 消耗 |
|------|----------|----------|------|
| 近战 | 剑、矛、锤 | 挥砍 / 刺 | 无 |
| 远程 | 弓、枪 | 发射弹药 | 弹药消耗 |
| 魔法 | 法杖、魔导书 | 投射魔法球 | MP 消耗 |
| 投掷 | 手雷、飞刀 | 抛物线投掷 | 物品消耗 |

### 5.2 伤害公式

```
最终伤害 = (武器基础伤害 + 随机浮动 ±15%) × 暴击系数 - 敌人防御

暴击系数: 默认 1.0，暴击时 × 2.0
暴击率: 默认 4%，可由装备提升

击退力: 视武器类型，影响 Rigidbody2D 速度
```

### 5.3 无敌帧（iFrame）
- 玩家受击后有 0.5 秒无敌期，防止连续受伤
- 闪烁动画提示玩家当前处于无敌帧

### 5.4 状态效果

| 效果 | 来源 | 效果描述 | 持续时间 |
|------|------|----------|----------|
| 中毒 | 腐化怪物 | 每秒损失 2 HP | 10s |
| 燃烧 | 岩浆/火焰怪 | 每秒损失 5 HP | 5s |
| 减速 | 冰系敌人 | 移动速度 -30% | 3s |
| 再生 | 再生药水 | 每秒回复 2 HP | 8s |
| 力量 | 力量药水 | 攻击力 +20% | 60s |

### 7.1 普通敌人

| 敌人名称 | 出现区域 | HP | 攻击力 | 特殊行为 |
|----------|----------|----|----|----------|
| 绿史莱姆 | 地表（白天）| 14 | 6 | 弹跳追击 |
| 蓝史莱姆 | 地下 | 22 | 10 | 弹跳追击 |
| 飞眼怪 | 地表（夜晚）| 30 | 8 | 飞行俯冲 |
| 骷髅 | 地下 | 45 | 12 | 扔骨头 |
| 地穴蝙蝠 | 洞穴 | 20 | 9 | 飞行袭击 |
| 岩浆蝙蝠 | 地狱层 | 80 | 30 | 飞行+燃烧 |
| 腐化腐尸 | 腐化地区 | 35 | 14 | 中毒攻击 |

### 7.2 AI 行为模式（FSM 有限状态机）

```
[巡逻状态]
  → 检测玩家进入范围 → [追击状态]

[追击状态]
  → 到达攻击距离 → [攻击状态]
  → 玩家逃跑超出范围 → [巡逻状态]
  → HP < 30% → [狂暴状态]

[攻击状态]
  → 执行攻击动作
  → 攻击冷却中 → [追击状态]

[狂暴状态]
  → 移速+30%，攻击力+20%
  → 持续追击直到死亡
```

### 7.3 Boss 设计

#### Boss 1：眼球之王（入门 Boss）
- **召唤方式**: 使用"疑惑的眼睛"道具，或夜晚随机触发
- **HP**: 2800
- **阶段**:
  - 第一阶段（HP > 50%）：飞行俯冲攻击，释放飞眼小怪
  - 第二阶段（HP < 50%）：变形为更凶猛形态，速度+50%，连续冲刺
- **掉落**: 组织 ×30~50，黑暗晶石，眼球之杖（概率）
- **Unity 实现**: `Animator` 控制变形动画，`NavMeshAgent` 飞行路径（或自定义寻路）

#### Boss 2：石之巨人（地下 Boss）
- **召唤方式**: 首次进入深层矿脉区域触发
- **HP**: 8000
- **阶段**:
  - 第一阶段：地震踩踏，投掷石块
  - 第二阶段（HP < 40%）：脱落护甲，暴露弱点，加速攻击
- **掉落**: 古代矿石 ×5~10，石之精华（特殊材料）

#### Boss 3：暗影领主（最终 Boss）
- **召唤方式**: 使用"暗影核心"（深层材料合成）
- **HP**: 25000
- **阶段**:
  - 三阶段变形，每阶段改变攻击模式
  - 最终阶段召唤分身，释放全屏弹幕
- **掉落**: 传说级装备，通关成就解锁

## 8. NPC 与村庄系统

### 8.1 NPC 入住条件

NPC 会在玩家建造**符合条件的房间**后自动入住：
- 房间要求：至少 6×10 大小，有墙壁、门、灯、桌、椅
- 每个 NPC 占用独立房间

### 8.2 NPC 列表

| NPC | 入住条件 | 出售物品/功能 |
|-----|----------|---------------|
| 商人 | 建造第一个房间 | 药水、基础工具、宝箱 |
| 护士 | 玩家 HP 达 100 | 花费金币立即回血 |
| 爆破师 | 获得炸药 | 出售炸药、地雷 |
| 法师 | 击败第一 Boss | 出售魔法药水、法术材料 |
| 武器商 | 硬模式激活 | 出售高级武器 |
| 向导 | 游戏开始即存在 | 提示合成配方（免费） |

### 8.3 NPC 交互
- 点击 NPC 开启对话框 + 商店界面
- 使用**金币**货币体系（铜币 100 = 银币 1，银币 100 = 金币 1，金币 100 = 铂金币 1）
- 夜晚敌人可以攻击 NPC，NPC 会用弱武器反击（掉血但不会永久死亡，第二天复活）

## 11. 技术架构建议

### 11.1 Unity 项目结构

```
Assets/
├── Scripts/
│   ├── World/          # 世界生成、Chunk 管理
│   ├── Player/         # 玩家控制、输入
│   ├── Combat/         # 战斗、伤害计算
│   ├── Items/          # 物品、合成、背包
│   ├── Enemies/        # 敌人 AI、Boss 逻辑
│   ├── NPC/            # NPC 行为、商店
│   ├── UI/             # 所有 UI 脚本
│   ├── Managers/       # GameManager、SaveManager、AudioManager
│   └── Utils/          # 通用工具类
├── Prefabs/
│   ├── Tiles/          # RuleTile 预制件
│   ├── Enemies/
│   ├── Items/
│   └── UI/
├── ScriptableObjects/  # 物品数据、敌人数据（数据驱动）
├── Tilemaps/           # Tile 贴图资源
├── Animations/
├── Audio/
└── Scenes/
    ├── MainMenu
    ├── GameScene
    └── LoadingScene
```

### 11.2 关键技术选型

| 功能 | Unity 方案 |
|------|-----------|
| Tile 渲染 | `Tilemap` + `RuleTile`（Unity 2D Extras） |
| 玩家物理 | `Rigidbody2D` + 自定义物理控制器 |
| 输入 | `Unity Input System（新版）` |
| 敌人 AI | 自定义 FSM（不使用 NavMesh，因为是 Tile 世界）|
| 世界生成 | 纯 C# Noise 算法（`SimplexNoise`/`PerlinNoise`）|
| 存档 | `JsonUtility` + `BinaryWriter`（压缩） |
| 音频 | `AudioSource` + `AudioMixer`（分层音量控制）|
| 摄像机 | `Cinemachine 2D Camera`（跟随+边界限制）|
| UI | `Unity UI（Canvas）`，背包用 `GridLayoutGroup` |

### 11.3 性能优化要点

1. **Chunk 系统**：只激活玩家附近 5×5 个 Chunk 的 Tilemap
2. **对象池（Object Pool）**：子弹、粒子、掉落物 都用对象池
